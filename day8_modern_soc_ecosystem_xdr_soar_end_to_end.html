PHASE 4

Extended Detection & Response (XDR)

Why investigate email, endpoint, and firewall alerts separately when they're part of the same attack?

Traditional Investigation
→ Open Firewall Console
→ Open EDR Console
→ Open SIEM
→ Open Email Gateway
Fragmented view across multiple consoles
XDR Investigation
→ Single Unified Timeline
→ Email Received
→ PowerShell Executed
→ Malware Downloaded
→ Credential Theft
Everything in one place
SIEM vs XDR
SIEM
  • • Collects logs
  • • Broad visibility
  • • Search focused
  • • Centralized storage
XDR
  • • Correlates telemetry
  • • Deep context
  • • Investigation focused
  • • Automated correlation

PHASE 7

A Day in the Life of a SOC Analyst

What does a typical day look like for an L1 SOC analyst?

09:00 AM — Review Dashboard
Check new alerts, open incidents, and critical system status
10:00 AM — Investigate Alert
Review failed login alert. Collect evidence, determine if incident
11:00 AM — Threat Hunting
Proactive hunt for PowerShell abuse across the environment
01:00 PM — Incident Response Meeting
Daily standup with L2/L3 analysts and SOC manager
03:00 PM — Case Documentation
Update tickets, write investigation summaries, close resolved cases
05:00 PM — Detection Improvement
Suggest rule improvements, update playbooks, share findings
